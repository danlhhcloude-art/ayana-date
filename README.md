# Для Аяны

Две мини-игры на чистом HTML, CSS и JavaScript. Без картинок, без библиотек, вся графика рисуется на Canvas.

## 1. Ночной город (`/`)

Приглашение на свидание в стиле аниме-ночного города. Силуэт с зонтом ловит падающие звёзды, каждая зажигает точку в созвездии-сердце и открывает строчку признания. После семи звёзд дождь стихает и появляется вопрос. Кнопка «Нет» убегает, кнопка «Да» растёт. После «Да»: салют, рассвет, выбор, куда пойти.

Эффекты: дождь с брызгами, три слоя города с параллаксом (на телефоне от наклона), отражения в лужах, неоновые вывески, молнии, созвездие, салют, рассвет. Звук на WebAudio: шум дождя, аккорды, мелодия с эхом.

Тексты: массивы `LINES` и `STAGES` в `index.html`.

## 2. Кинотеатр (`/kino/`)

**Слова о любви.** Бесконечная колода: «я тебя люблю» на 55 языках и 38 слов, которых нет в русском (saudade, cafuné, 恋の予感, mamihlapinatapai…). Нужно угадать язык из четырёх вариантов. За правильный ответ сердечко, значение слова и короткая фраза для Аяны. Каждые три угаданных открывают новый фрагмент фильма.

**Кино.** Генератор кинофрагментов, которых не существует. Для каждого заново собираются: название фильма, год, жанр, режиссёр, одна из восьми сцен (дождь, снег, закат, поезд, крыша, сакура, фестиваль, кафе), два силуэта, где он застенчиво чешет затылок, и четыре реплики признания из сотен комбинаций. Титры, сценарная ремарка, субтитры с печатью, зерно плёнки, виньетка, мерцание, засветы, медленный наезд камеры. Кадр можно сохранить как картинку. Звук: гул проектора и редкие ноты пианино с эхом.

Тексты: `PHRASES`, `WORDS`, `OPEN`, `SHY`, `LOVE`, `CLOSE`, `TITLES` в `kino/index.html`.
