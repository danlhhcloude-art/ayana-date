# Для Аяны 💌

Страничка-приглашение на свидание, сделанная с нуля на чистом HTML/CSS/JS.

**Что внутри**
1. Конверт с печатью-сердечком, который нужно открыть.
2. Письмо, которое печатается по буквам.
3. Нарисованный котик с цветком: с каждым «Нет» краснеет сильнее, потом грустит и плачет. Кнопка «Нет» уменьшается и убегает от курсора и от пальца, кнопка «Да» растёт.
4. После «Да» у котика глаза-сердечки, сердечный салют и выбор, куда идти.
5. Нежная фоновая музыка (арпеджио на WebAudio, без файлов), плывущие сердечки и лепестки.

Единственная зависимость: `canvas-confetti` с CDN для салюта из сердечек.

Все фразы лежат в `index.html` в массивах `LINES` (письмо) и `STAGES` (реплики котика и кнопок).
