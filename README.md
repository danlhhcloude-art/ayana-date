# Аяна, один вопрос… 💗

Милая страничка-приглашение на свидание. Кнопка «Нет» с каждым нажатием становится всё жалобнее, кнопка «Да» растёт, а при согласии летят сердечки.

Основано на [CodeKageHQ/Ask-out-your-Valentine](https://github.com/CodeKageHQ/Ask-out-your-Valentine) (MIT).

Чтобы поменять тексты, открой `index.html`: массивы `NO_BUTTON_MESSAGES` и `SUBTEXTS`, гифки лежат в папке `images/`.
