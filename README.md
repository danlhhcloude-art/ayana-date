# Для Аяны

Мини-игра-приглашение на свидание в стиле аниме-ночного города. Чистый HTML, CSS и JavaScript, вся графика рисуется на Canvas, без картинок и библиотек.

**Как это устроено**
1. Интро: неоновое имя, город под дождём, луна.
2. Игра: силуэт с зонтом ловит падающие звёзды. Управление пальцем, мышкой или стрелками. Каждая пойманная звезда зажигает точку в созвездии-сердце и показывает одну строчку признания. Всего семь.
3. Когда созвездие собрано, дождь стихает и появляется вопрос. Кнопка «Нет» со второй попытки убегает, кнопка «Да» растёт.
4. После «Да»: салют над городом, рассвет, выбор, куда пойти, и финальное сообщение.

**Эффекты**: дождь с брызгами, три слоя города с параллаксом (на телефоне реагирует на наклон), отражения в лужах, пульсирующие неоновые вывески, редкие молнии, созвездие, салют, рассвет. Звук генерируется на WebAudio: шум дождя, мягкие аккорды, эхо-мелодия, перезвон при поимке.

**Тексты** лежат в `index.html`: массив `LINES` (семь строчек за звёзды) и `STAGES` (реплики при нажатии «Нет»).
